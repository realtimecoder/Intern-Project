# Logistics & Delivery Route Efficiency Tracker

## Internship Data Analytics Project

A practical Data Analytics project that analyzes delivery routes, delays, fuel usage,
driver performance, and on-time delivery.

### Business Problem
A logistics company wants to identify:
- Which routes are inefficient?
- Which drivers/vehicles perform best?
- How much time is lost because of traffic/weather?
- Which routes have high fuel cost?
- Where can delivery operations be optimized?

### Tech Stack
- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- CSV dataset

### KPIs
- Total Orders
- Delivery Completion Rate
- On-Time Delivery Rate
- Average Delay
- Total Distance
- Total Fuel Cost
- Route Efficiency

### Run the dashboard
```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal.
